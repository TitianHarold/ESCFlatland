# ESCFlatland

平面国交互短片。默认观看页每次点击播放一个完整动作情节，等待时内窗继续流动；追光时可以长按加速，松开恢复正常速度。右上几何图标打开工作台，工作台左上可返回观看页。

Published with GitHub Pages from `main` / `docs`.

The initial website was exported with `git archive` from stable source commit `d8bcdb3b9f723c24acaad1be290770bdb5f83c3a`; only the viewer/workbench navigation and this publication layout were added.
