# 平面国 · 分镜制作表

打开 `index.html` 或 `分镜制作表.html`。默认 B「例行塑形」与 F2 配色，可切换 A「四组夹具」及四套配色。

- A 38段、自动预览107.65秒；B 38段、自动预览118.7秒。互动允许等待、抗拒、点击工作、逐块剥漆和长按追逐，总时长随操作变化。
- 房门经带障碍约束的真实路径搜索连通街网。三名士兵全程近距押送至门内，点击让孩子即时缩紧、缓慢后退，镜头稍滞后地回移；被催继续时不加速补路程。
- 家庭等待时孩子小幅轻摇探索，父母更沉稳。真实接触时父母快速内缩和躲避、明显减速停住；母亲的细长轮廓局部内凹，不以线性缩放代替。
- 接收传送带直接接管门内角色，门口抵抗状态不延续为停步。工厂镜头保留角色软区，抵抗不带动整座工厂；全景拉远和推近连续，全景期间角色仍沿带前行。
- B版三站分别表现逃向点击边缘后被封边挡回、长按内摇被夹紧、逆转抗拒喷漆。每完成一站，圆环累计三分之一变红。输送段仍允许慢速逆行，耗尽后按正常带速继续，不加速追回落后距离。
- 内心首次出现两颗微光，之后每次补一颗。六次发现后沿真实点击轮廓照亮全景，等待点击中央柔光，才缓慢收拢为体内同一颗光。
- 追光镜头由实际速度驱动：松手舒展、长按高速贴身。短点击逐块剥漆，蓄满后1.6秒终段冲刺先用1.2秒剥净剩余黑漆，最后0.4秒归白。光的位置、亮度和运动连续衔接白场双手。
- 白场四次点击：张手、半握、落光晕开显现左调色盘右画笔、再次点击白场进入内心。工具显现后独立光点不再出现。先显示 `Welcome to explore new dimensional`，下方再显示 `Alice escape flatland`，完成后才显示重播。
- 每段提供完整剧情、场景角色、画风颜色、动作节奏、机位、首帧、尾帧和连续性要求；同一大框可一次复制。
- 152张当前程序首尾帧，四配色×两版×六场景，共48张配色对照。程序帧为离线Canvas采样，不是新手绘图或浏览器截图。
- 原有六项角色素材及原图保持。新画笔与调色盘手部图独立加入结尾参考，旧握笔图继续保留。画面选择只切换参考图片，不覆盖当前完整剧情与视频提示词。
- 少女与双手当前展示偏白肤色版本；素材区分别保留当前PNG与原图PNG下载，布局不变。

`shots-detailed.json` 保存两版镜头和真实时间映射。`frames/detailed/manifest.json` 与 `frames/palette-preview/manifest.json` 保存采样来源；各版 CSV/TXT 可离线使用。无版本后缀的导出默认为B版。

维护命令：

```sh
node render-code-frames.cjs all
python3 build_board_r2.py
```

`build_board_r2.py` 只重建表格和导出，不生成或覆盖角色原图。`art-pairs.json` 与图像生成原词保留为历史来源；旧专用fullPrompt不参与当前剧情复制。
