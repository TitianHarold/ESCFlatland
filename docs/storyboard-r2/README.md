# 平面国 · 分镜制作表

打开 `index.html` 或 `分镜制作表.html`。默认 B「例行塑形」与 F2 配色，可切换 A「四组夹具」及四套配色。

- A 38段、自动预览105.65秒；B 38段、自动预览116.7秒。互动允许等待、抗拒、点击工作、逐块剥漆和长按追逐，总时长随操作变化。
- 房门经带障碍约束的真实路径搜索连通街网；柔性构图让角色先在画面软区内抗拒，越界再阻尼跟随。门口拉远、工厂全景和随后推近连续衔接，全景期间角色仍沿带前行。
- 持续长按抗拒、按用力时长累积消耗；红圈后只随传送带前行，保留落后距离，不加速追赶。工作台播放／暂停同时控制角色、机器、镜头和过渡。
- 内心照亮后停留，再缓慢收拢成体内同一颗光。B版每次短点击剥一块黑漆，长按只加速。引导光在稍远前方游动，主角朝向带轻微反应延迟。
- 白场细分第一次张手、第二次半握、第三次落光握笔；随后双手淡出，仅存光点扩散为内心世界，出现精确英文 `welcome to explore a new dimension`。结束后才显示重播。
- 每段给出完整剧情、场景角色、画风颜色、动作节奏、机位、首帧、尾帧和连续性要求；同一大框可一次复制。
- 152张当前程序首尾帧，四配色×两版×六场景，共48张配色对照。程序帧为离线Canvas采样，不是新手绘图或浏览器截图。
- 原有手绘图对、六项角色素材与全部原图保持。新增握笔手部图为独立参考，不替换旧图。画面选择只切换参考图片，不覆盖当前完整剧情与视频提示词。
- 少女与双手当前展示偏白肤色版本；素材区分别保留当前PNG与原图PNG下载，布局不变。

`shots-detailed.json` 保存两版镜头和真实时间映射。`frames/detailed/manifest.json` 与 `frames/palette-preview/manifest.json` 保存采样来源；各版 CSV/TXT 可离线使用。无版本后缀的导出默认为B版。

维护命令：

```sh
node render-code-frames.cjs all
python3 build_board_r2.py
```

`build_board_r2.py` 只重建表格和导出，不生成或覆盖角色原图。`art-pairs.json` 与图像生成原词保留为历史来源；旧专用fullPrompt不参与当前剧情复制。
