# 平面国 · 90秒分镜制作表 R2

打开[分镜制作表.html](分镜制作表.html)。离线使用时保留整个目录；页面数据已内联，不需要服务器读取JSON。

- 主线90秒，15个母镜号，36个动作段。
- 72张代码首尾帧，四套配色共24张代码预览。
- 8个图对使用14张唯一图片；包含直接生成的手绘图、纯白代码帧和批准双手素材的代码合成帧。007A尾帧同时是007B首帧，014D纯白尾帧同时是015A首帧。
- 36段各有完整八栏视频提示词，四套标准配色共144份；015A使用跨配色共用的中性白场与双手。当前提示词可整段复制，TXT/CSV可整表下载。

压头先慢张开蓄力，再快速砸至真实接触，持压破坏内窗后退开，硬壳保持不变。旋转盘迅速起转、高速完成十二圈、短促刹停。追光末段视野归于纯白，奔跑在白场结束；015A为静止第一人称抬手、翻掌、屈指。双手是少女纤细长指，掌心自视，拇指分别在画面左右外侧，颜料稀疏不对称，多数指头干净。

## 配色

方案为原配色、F2奶油芥末灰绿、F3奶油青绿鲑红、F4纸灰橄榄砖红。制作表切换具体色值和固定预览；手绘图仅使用实际存在的版本，不做CSS滤镜换色。

动画工作台可精调八个语义色，显式应用后保留进度与模式重建画面。相同网站来源下，制作表、动画工作台与观看页读取同一个本机键`flatland.palette.v1`；不同网站或本地文件不承诺跨来源同步。白场与015A中性图对始终纯白。

## 数据与来源

- `shots-detailed.json`：36段的动作、时间、首尾要求、八栏完整视频词。
- `art-pairs.json`：8个图对、专用视频词、来源和历史图引用。旧持压末图及旧几何末图仍作为历史资料保留。
- `首尾帧美术生成提示词.json`：原始图生记录；`newActualCallsR9`追加这次实际提交原词与已确认引用。
- `new-image-prompts-r9.json`：少女张掌、轻屈指、压头退开三次实际原词。
- `frames/detailed/manifest.json`、`frames/palette-preview/manifest.json`、`frames/ending/manifest.json`：各图采样时间与来源。局部更新帧和较早代码快照按各自metadata区分。
- `frames/alternative/`：旧尾段资料，保留文件但不在当前制作表展示。
- `视频提示词-*.txt`、`分镜制作表-*.csv`：四套完整导出。页面导出还会采用当前选中的图对专用视频词。

图像生成原词和视频动作提示词分开保存；静态首尾不等于中间视频已经生成。001–002手绘构图的门在右侧，早期代码图的门在上侧，其来源保留在数据中。

## 维护

在本项目工作目录执行：

```sh
python3 build_art_pairs.py
python3 build_board_r2.py
```

生成器使用Python标准库，读取同目录JSON与图片，再复制动画工作台的`palette.js`。发布入口为`docs/storyboard-r2/分镜制作表.html`。
