# 平面国 · 分镜制作表

打开 `index.html` 或 `分镜制作表.html`。默认 B「例行塑形」与 F2 配色，可切换 A「四组夹具」及四套配色。

- A 38段、自动预览107.65秒；B 38段、自动预览118.7秒。互动允许等待、抗拒、点击工作、逐块剥漆和长按追逐，总时长随操作变化。
- 房门经带障碍约束的真实路径搜索连通街网。三名士兵全程近距押送至门内，并在门口遮挡中完成交接，工厂内部不再出现，点击让孩子即时缩紧、缓慢后退，镜头稍滞后地回移；被催继续时不加速补路程。
- 家庭等待时孩子小幅轻摇探索，父母更沉稳。真实接触时父母快速内缩和躲避、明显减速停住；母亲的细长轮廓局部内凹，不以线性缩放代替。
- 接收传送带直接接管门内角色，门口抵抗状态不延续为停步。工厂镜头保留角色软区，抵抗不带动整座工厂；全景拉远和推近连续，全景期间角色仍沿带前行。
- B版真实轮廓进入工位边框即切换节点行为，不保留输送段后退。封边点击依次五方向逃离，收紧蓄力后加速冲出，被对应边突然扣下、撞停顶回并受压短震；压实点击左右扭，长按膨胀身体，五根定长定粗的刚性黑边各自向外平移、角部接缝张开，松手后嘣地合回原锁位；喷漆短按拖慢实际转位，长按逆时针扭回一点，再被机器强制归正停稳后喷中。三道工序自动完成，点击与长按只触发可选抵抗，不需凑次数或填圈。反应期间仅暂停主角当前节点工序，角色反应与夹具回位继续，背景工人和流水线照常走；未完成的封边反应、压实短按和喷漆抵抗回稳后续跑冻结工序，不跳步、不补速；达到完成条件则交接下一段传送带。五边封合且最后碰撞回稳后立即离站，后续输入切为传送带倒退；同一组定长斜接边条连续保留到压实，不切换画法。每次抵抗和重复点击都承接当前可见姿态，已锁边不重开。压实松手或耗尽后猛反压到锁紧态，保压后再按工序退夹离站，不恢复暂停前张开的间隙。输送段仍允许慢速逆行，耗尽后按正常带速继续，不加速追回落后距离。
- 内心首次出现两颗微光，之后每次补一颗。六次发现后沿真实点击轮廓照亮全景，更大更亮的中央柔光以2.4秒周期柔和呼吸，最暗时仍清晰；等待点击确认，才缓慢收拢为体内同一颗光。
- 追光镜头由实际速度连续调度平面、慢速与高速透视：蓄满前松手，机位和投影大小平滑退回慢速，蓄满后锁定最终冲刺。短点击逐块剥漆，蓄满后1.6秒终段冲刺先用1.2秒剥净剩余黑漆，最后0.4秒归白。蓄力最后40%开始随实际速度渐进拉散，末冲达到沿右上方向的细长彩色形体；蓄满前松手时连续收回。光的位置、亮度和运动连续衔接白场双手。
- 白场四次点击：已张开的双手在最终位置用1.2秒淡入、半握、落光晕开显现左调色盘右画笔、再次点击白场进入内心。工具显现后独立光点不再出现。中央只显示 `Let’s explore a new dimension`，完成后才显示重播。
- 每段提供完整剧情、场景角色、画风颜色、动作节奏、机位、首帧、尾帧和连续性要求；同一大框可一次复制。
- 152张当前程序首尾帧，四配色×两版×六场景，共48张配色对照。程序帧为离线Canvas采样，不是新手绘图或浏览器截图。
- 原有六项角色素材及原图保持。新画笔与调色盘手部图独立加入结尾参考，旧握笔图继续保留。画面选择只切换参考图片，不覆盖当前完整剧情与视频提示词。
- 少女与双手当前展示偏白肤色版本；素材区分别保留当前PNG与原图PNG下载，布局不变。

`shots-detailed.json` 保存两版镜头和真实时间映射。`frames/detailed/manifest.json` 与 `frames/palette-preview/manifest.json` 保存采样来源；各版 CSV/TXT 可离线使用。无版本后缀的导出默认为B版。

维护命令：

```sh
node render-code-frames.cjs all
python3 build_board_r2.py
```

`build_board_r2.py` 只重建表格和导出，不生成或覆盖角色原图。`art-pairs.json` 与图像生成原词保留为历史来源；旧专用fullPrompt不参与当前剧情复制。
